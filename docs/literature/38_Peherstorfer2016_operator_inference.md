# [38] Peherstorfer & Willcox 2016 — Data-driven operator inference for nonintrusive projection-based model reduction

- **Venue**: Computer Methods in Applied Mechanics and Engineering 306:196–215，DOI 10.1016/j.cma.2016.03.025
- **Domain / Tier / Priority**: Reduced-order models / 3 / Low
- **Link**: 表中 MIT DSpace 链接用 curl 访问返回空页；全文取自 UT Austin Oden 研究所公开版本（kiwi.oden.utexas.edu/papers/Non-intrusive-model-reduction-Peherstorfer-Willcox.pdf）
- **依据**: ✅ 已读全文（§1–5：问题设定、算子推断 Theorem 1、计算成本、实际注意事项、四个数值例子）。标【推断】的是我们的映射。

> 一句话（摘要）：针对基于时间相关 PDE 的全阶模型，提出**非侵入式**投影降阶。传统投影需要全阶算子，而很多时候全阶模型是只给出状态轨迹和输出的黑箱。operator inference 只用初始条件、输入、状态轨迹和输出，通过**最小二乘**推断降阶算子；数据足够时，在 Frobenius 范数下收敛到侵入式投影得到的算子。适用于**状态线性或含低阶多项式非线性**的模型。数值例子包括线性气候模型和含三阶多项式非线性的管式反应器。

## 1. 瓶颈
侵入式降阶需要全阶模型的算子，而很多模型（包括虽有源码但过于复杂的"社区代码"，如文中的 GCM）只能当黑箱用。

## 2. 手段
- 收集全阶模型的状态快照 → POD 基 → 投影得到降阶状态轨迹。
- 最小二乘拟合降阶算子（线性项 + 多项式非线性项 + 输入项）。
- 数据足够时，推断出的算子收敛到侵入式算子（Theorem 1：时间步长 → 0、维数 → N，且数据矩阵满列秩时，‖Â − Ã‖_F 可以任意小）。
- 求解是 n 个独立的线性最小二乘问题，导数用有限差分近似。
- **§3.6 实际问题**：数据矩阵条件数大时（相邻时间步状态几乎线性相关，或状态很快收敛到稳态），推断的算子误差很大、降阶模型可能不稳定。办法是**合并多条不同初始条件/输入的轨迹**，让数据中有更多瞬态信息；用 Â 的特征值检查稳定性，不稳定就减小维数。

## 3. 省在哪一项
**每步计算**（用降阶模型做预测）。

## 4. 快了多少，代价是什么（原文 §5）
- 原文**没有给出统一的加速倍数**，也没有报告降阶模型的运行时间，重点在于证明可行性和收敛性。
- 四个例子：热方程（N = 127，维数 8，与侵入式误差相当；线性且输入恒定时等价于 DMD）；Burgers 方程（N = 127，需要合并 10 条随机输入的轨迹，维数 > 10 时部分参数不稳定）；管式反应器（N = 51，三阶非线性，用 3000 个随机初始条件各跑一步，能正确找到极限环出现的临界 Damköhler 数）；**MIT GCM 海洋环流**（N = 10,800，当黑箱用，6 条轨迹各 10⁴ 步，维数 > 14 时不稳定，误差随维数下降的速度与 POD 投影误差相近）。
- 推断的计算量随时间步数和全阶自由度**线性**增长；但随多项式非线性的阶数**指数**增长，所以只适用于低阶多项式非线性。

## 5. 怎么证明结果没变
与全阶模型的状态和输出轨迹比较；证明推断算子收敛到侵入式算子；GCM 例子比较流场图。

## 6. 假设
- 全阶模型是时间相关的 PDE，**状态线性或含低阶多项式非线性**（结构已知）。
- 确定性的状态轨迹数据。
- GCM 例子中输入范围只取 [0.099, 0.100]，作者说输入范围再大，解的行为差别太大，降阶模型就难以近似——即只在很窄的工况范围内有效。

## 7. 能否用于 MATSim？怎么用
**🟡（推测性）理论上能用，实际收益存疑：**
- 【推断】设想：把 MATSim 逐轮的路段出行时间场（或宏观指标）当作"状态"，用前若干轮的快照学一个低维的"轮到轮"映射，然后外推到稳态，或者给 Anderson acceleration（[29](29_Khatiwala2024_spinup_sequence_acceleration.md)）提供更好的方向。
- 障碍：
  1. 本方法要求动力学是**已知形式的低阶多项式**，而 MATSim 的逐轮变化由离散 agent 决策驱动，没有这种结构；
  2. 数据有强噪声，本文没有处理噪声；而且 §3.6 说明，状态接近稳态时数据矩阵会病态——MATSim 后期正是这种情况；
  3. 外推出的出行时间场还要被 agent 消化，效果不确定。
- 优先级低，作为"非侵入式降阶"的代表放进对照表。
