# [59] Liu & Meidani 2023 — End-to-End Heterogeneous Graph Neural Networks for Traffic Assignment

- **Venue**: *Transportation Research Part C* 165:104695, 2024（doi:10.1016/j.trc.2024.104695，据 [56] 的参考文献）；本笔记依据 arXiv [2310.13193](https://arxiv.org/abs/2310.13193)（UIUC）
- **领域**: 11 学习型模拟器（近期，交通）
- **依据**: ✅ 已读全文（arXiv 2310.13193 **v3，2024-10**，18 页：§1–6、表 1–6、参考文献）。

> 一句话：用**异构图神经网络**做静态 UE 交通分配的代理模型：在真实路段之外加入连接 OD 对的"虚拟 link"，并把节点流量守恒写进损失函数。在 Sioux Falls、East Massachusetts、Anaheim 上比其他神经网络更准、收敛更快，并能推广到不同的路网拓扑；OD 需求缺失 20–40% 时也较稳健。

## 1. 瓶颈
大网络上反复求解交通分配（如韧性分析、网络设计的下层问题）计算量大。

## 2. 手段
- 两类边：真实道路 + 虚拟 OD 边，用自适应图注意力分别处理。
- 损失函数中加入流量守恒约束（软约束）。
- 两种训练策略，使模型可推广到不同拓扑的网络。

## 3. 省在哪一项
**运行次数**（训练好之后替代求解器）。

## 4. 快了多少，代价是什么
- 每个网络、每种扰动水平生成 5000 个样本（OD 需求 ×U(0.5, 1.5)，容量按轻/中/重扰动缩减），80/20 划分，Frank–Wolfe 求 UE 作为标签。
- 计算时间（§5.1.3）：
  - 生成标签（求 UE）：Sioux Falls 56.8 min、EMA 575.2 min、Anaheim 2612.5 min；
  - 训练：26.8 / 28.9 / 59.7 min；
  - 推断：每 1000 个图 0.13 / 0.15 / 0.31 min。
  - 本文没有直接给"加速倍数"；按上面数字，摊到单个情景的推断时间远小于求解时间，但前提是先付出生成数千个标签的成本。
- 精度（表 2）：HetGAT 的流量 MAE 在 EMA 上比次优模型低 39.5% / 56.4% / 38.8%（LMH-LMH / L-M / M-H 三种设置），Anaheim 低 27.2% / 47.4% / 33.1%；Anaheim 上路段利用率 MAE 约 3%。
- OD 缺失 20/30/40%：仍优于 GCN、GAT（表 3）；改变拓扑（增删路段、100/300 节点随机图）：用迁移学习或"补虚拟节点"统一训练后仍领先，但精度有所下降（表 4–6）。
- 代价：训练数据来自传统静态 UE 求解器；**只学静态流量**（作者把动态列为未来工作）；流量守恒只是软约束。

## 5. 怎么证明结果没变
在测试集上与求解器得到的 link 流量、流量容量比比较（MAE、RMSE 等），5 折交叉验证。

## 6. 假设
静态、确定性的 UE。

## 7. 对我们意味着什么
- 【推断】时间账本说明代理的门槛：Anaheim 上要先花约 44 小时求 5000 个 UE 才能训练。这与 [56](56_Li2026_DiLLSUE_Anderson_SUE.md) 引用的 GAT 盈亏平衡点（约 2,100–2,900 个情景）一致：**只有情景数很多时整体代理才划算**，对单次 MATSim 运行的加速没有直接帮助。
- 与 [49 Natterer](49_Natterer2025_GNN_surrogate_MATSim.md) 一样，是"替代整次求解"的外循环工具；对 MATSim 的动态、随机、全日计划场景还很远。
- 【推断】只作为"学习型模拟器在交通中的近期进展"引用。
