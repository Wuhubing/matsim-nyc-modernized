# [27] Laio & Parrinello 2002 — Escaping free-energy minima (metadynamics)

- **Venue**: PNAS 99(20):12562–12566（arXiv cond-mat/0208352v1）
- **Domain / Tier / Priority**: MD enhanced sampling / 2 / Low
- **Link**: https://arxiv.org/abs/cond-mat/0208352
- **依据**: ✅ 已读全文（arXiv v1，4 页：方法、1D 例子、参数选择、NaCl 和 alanine dipeptide 两个应用、讨论）。标【推断】的是我们的映射。

> 一句话（摘要）：在少数几个**集体坐标（collective coordinates）**张成的空间里，用粗粒化、非 Markov 的动态探索多维自由能面。核心是一个**历史相关的势能项**：它随时间填平自由能面上的极小点，从而高效探索，并准确确定自由能面（作为集体坐标的函数）。

## 1. 瓶颈（原文）
自由能面有多个被大能垒隔开的局部极小时，"a simulation started in one minimum will be able to move spontaneously to the next minimum only under very favourable circumstances"。例如构象变化、蛋白质折叠、一阶相变、化学反应。

## 2. 手段
- 选少量集体坐标 s_i。用 P 个受约束的副本估计力 F_i = −∂F/∂s_i，然后在 s 空间做粗粒化的最速下降步（式 1）。
- **历史相关偏置**（式 2）：把力替换为 φ_i − ∂/∂σ_i Σ_{t′≤t} W·exp(−|σ − σ^{t′}|²/(2δσ²))，即在走过的每个点上叠加一个高斯，"discourage the system from revisiting the same spot"。
- 长时间极限下，高斯之和 → −F(s)（式 3），所以自由能面是副产品。
- 1D 例子（Fig. 1，三个势阱）：约 20 步填满起始阱，约 80 步填满第二个阱，约 320 步填满整个势能面。

- 参数选择：高斯高度 W 满足 W/δσ·e^{−1/2} = α·|F| 量级，α ≈ 0.5 时既能快速逃出极小又不破坏结构；δσ 选成"不加偏置时轨迹停留在阱内"的大小；缩放 Δs 由不加偏置的短跑经验确定（相当于预条件）。作者说将来应考虑自适应地确定这些参数。

## 3. 省在哪一项
**迭代次数**（加速稀有事件或跨越能垒，从而加速探索）。

## 4. 快了多少，代价是什么（原文）
- 原文没有给出相对普通 MD 的统一加速倍数，但给了两个应用：
  - **NaCl 在水中解离**（3 个集体坐标，6 个副本）：从接触离子对出发，**120 步粗粒化迭代**后解离；屏障 3.3 kcal/mol；过渡态处 Na 的配位数 5.28，与文献的"五配位"一致。对照：同样集体坐标下用逐渐降温的 Langevin 动态，收敛到解离态需要"well above 1000"次力的评估。
  - **alanine dipeptide**（2 个二面角）：约 45 步填满 C7eq 盆地，对应仅约 120 ps 的微观 MD；鞍点比 C7eq 高 2 kcal/mol，热力学积分的文献值 2.1；一维自由能曲线与文献相差 0.2 kcal/mol 以内。
- 稳健性：在解析势能面上，力的噪声达到 20–30% 时算法仍然有效，因为偏置只是"discourage (and not prevent)"重访，误差会平均掉，作者称之为"self-healing"。
- 代价：填满一个阱所需高斯数 ∝ (1/δσ)^n，**效率随集体坐标维数 n 指数下降**。n 大时只能用和阱一样大的高斯，牺牲分辨率；而且自由能面细节只能分辨到 δσ 的尺度。δσ 太大，系统会在盆地之间不规则地跳。

## 5. 怎么证明结果没变
在已知势能面的 1D 例子上，验证高斯之和收敛到 V(s)；应用中与热力学积分等已有结果比较（见第 4 问的数字）；对 NaCl 还用前后向轨迹检查过渡态是否是真正的动力学过渡态（200 fs 内绝大多数副本落入两侧盆地，没有反复穿越）。

## 6. 假设
- 存在**少数几个**能刻画慢过程的集体坐标；体系处于平衡态。
- 作者强调两个要素缺一不可：在集体坐标上做粗粒化动态 + 历史相关偏置。只在普通 MD 上加偏置能逃出极小，但得不到自由能面。
- alanine 例子中，集体坐标并不完整（没有包括溶剂），但结果仍然正确，因为被忽略的自由度对应的能垒很小。

## 7. 能否用于 MATSim？怎么用
**🟡 思路可借（"惩罚已经去过的地方"），严格形式不适用：**
- 【推断】对应思路是**禁忌或新颖性偏置**：在 agent 层面记录已经试过的创新（路径、出发时间区间、mode），生成新创新时避开已证明无效的区域。这直接针对"85% 无效创新"中**重复试探**的那部分。
- 【推断】先测量：无效创新中有多少是 agent 以前试过、后来被删除的方案？比例高时，这个手段收益大。
- 必须改造：
  1. 偏置只能用在**生成创新**环节，不能加到得分上，否则会改变均衡（与 [14](14_Eiben1999_parameter_control.md) 的"cheat"警告、[23](23_Andrieu2008_adaptive_MCMC.md) 的论证一致）；关掉创新后选择阶段不受影响。
  2. **原文的维数警告**：效率随集体坐标维数指数下降。在 agent 层面，"记住试过的方案"可以用离散的禁忌表实现，不需要连续的高斯；但若在人口层面用宏观集体坐标（如某走廊的 car 份额），只能选 1–3 个，否则无效。
- 【推断】"self-healing"一点值得借鉴：禁忌应该是"降低再次生成的概率"，而不是"禁止"。这样即使早期判断错误（某方案在当时的交通状态下无效，但后来变得有效），也还有机会被重新尝试。这和 [14](14_Eiben1999_parameter_control.md)、[23](23_Andrieu2008_adaptive_MCMC.md) 中"设下限"的结论一致。
