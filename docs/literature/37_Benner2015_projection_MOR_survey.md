# [37] Benner, Gugercin, Willcox 2015 — A survey of projection-based model reduction methods for parametric dynamical systems

- **Venue**: SIAM Review 57(4):483–531，DOI 10.1137/130932715
- **Domain / Tier / Priority**: Reduced-order models / 3 / Low（综述）
- **Link**: 表中 MIT DSpace 链接用 curl 访问返回空页；全文取自 UT Austin Oden 研究所公开的出版社版本（kiwi.oden.utexas.edu/papers/Parametric-model-reduction-survey-Benner-Gugercin-Willcox.pdf）
- **依据**: ✅ 已读全文正文（49 页中 pp. 483–521：§1–6；参考文献未读）。标【推断】的是我们的映射。

> 一句话（摘要）：大规模动力系统的数值模拟计算需求常常无法承受。模型降阶生成更快、更便宜，但能准确表示原系统行为的降阶模型。线性非参数系统的降阶已经成熟，**参数化**降阶则是较新的活跃领域。本文综述基于投影的参数化降阶方法（Petrov–Galerkin 投影、Krylov/矩匹配/插值、POD、平衡截断、贪心算法），比较各方法处理参数变化的方式及优缺点。

## 1. 瓶颈
大规模动力系统（参数化 PDE、大型参数化 ODE）的仿真代价；设计、控制、优化、UQ 需要在不同参数下反复求解。

## 2. 手段
- 用 POD、Krylov/有理插值（Theorem 3.1：每加一个向量就满足一个切向插值条件，还免费匹配梯度）、平衡截断（H∞ 误差 ≤ 2 × 截去的 Hankel 奇异值之和）、reduced basis 等构造低维子空间，再把方程投影上去。
- 非线性项用 EIM/DEIM 等"选择性采样 + 插值"处理。要真正省时间，参数依赖最好是**仿射**的（可以离线预计算各块）；否则每换一个参数都要做 O(n) 的运算。
- **POD（§3.3）**：对快照矩阵做 SVD，按"能量"阈值（常取 ≥ 99.9%）选维数 r。原文强调：POD 的最优性**只针对快照的重构误差**，不保证降阶模型求解的误差；快照怎么选，POD 理论本身没有给出指导。
- **参数采样（§3.4）**：参数少时用网格或拉丁超立方；d > 10 时需要自适应的**贪心采样**——每次找当前降阶模型误差（或误差估计量）最大的参数点，在那里跑一次全模型再更新。贪心法即使找不到全局最大误差点，也比随机采样好。
- §4：全局基 vs 局部基插值（在 Grassmann 流形上插值子空间、插值降阶矩阵、插值传递函数），各有利弊；只有插值传递函数能保证整个参数范围内稳定。
- **§5.8 无方程（equation-free）降阶**：没有状态方程、只有输入输出或黑箱模拟输出时，可以用 Loewner 框架，或"POD 子空间 + 插值/最小二乘/径向基函数"的非侵入式方法。
- §1 的对比：**数据拟合 surrogate 的离线构建是非侵入式的**（黑箱运行即可）；**投影降阶"fairly intrusive"**，需要把系统算子投影到降阶子空间，好处是保留了"系统状态"，可以随时间演化。

## 3. 省在哪一项
**每步计算 / 问题规模**（状态维数）。

## 4. 快了多少，代价是什么（原文 §1 引用的应用实例）
- 批量色谱优化：加速 54 倍；
- 污染物输运反演：从 100 多万个状态降到 800 个，约 3000 倍；
- 动脉流体-结构问题：约 28–450 倍；
- 核反应堆控制棒：30,000 倍，相对精度 10⁻⁴；
- 双线性化方法的例子：500 倍和 300 倍。
- 代价：**侵入式**，需要访问系统算子；一般非线性仍是挑战；§6 Outlook 指出，**时间相关或随机参数**的系统、高维参数空间仍是开放问题。

## 5. 怎么证明结果没变
与全阶模型比较误差；部分方法（如线性系统的平衡截断）有先验误差界；reduced basis 方法有可以不调用全模型计算的后验误差估计（§5.6），但界可能很松。
- §1.3 引用的比较：kriging 在建模用的条件范围内又快又准、且非侵入；投影降阶在**建模范围以外**的参数和初始条件上更灵活（因为保留了动力学）。

## 6. 假设
- 有**显式的控制方程**（ODE/PDE 算子），可以投影；解位于低维子空间附近；主要是确定性系统。

## 7. 能否用于 MATSim？怎么用
**❌ 不适用：**
- 【推断】MATSim 没有可以投影的控制方程，是离散 agent 的规则仿真。本文明确说投影降阶需要访问系统算子。
- §6 自己也承认，随机参数的系统是开放问题。
- 唯一的间接用法是对"逐轮演化的出行时间场"做**非侵入式**的数据驱动降阶（本文 §5.8 的 equation-free 路线，见 [38](38_Peherstorfer2016_operator_inference.md)），这已不是本文的主体方法。
- 【推断】§3.4 的贪心采样思想可以借用到 RQ2 的实验设计：在场景/参数空间中，优先在"新方法与原版差异最大"的场景上补跑验证，而不是均匀抽样。
- 列入对照表"不适用"一栏，作为了解"每步计算"上限的背景。
