# [40] Li, Kovachki, Azizzadenesheli, Liu, Bhattacharya, Stuart, Anandkumar 2021 — Fourier neural operator for parametric partial differential equations

- **Venue**: ICLR 2021（arXiv 2010.08895v3）
- **Domain / Tier / Priority**: Learned simulators / 3 / Low
- **Link**: https://arxiv.org/abs/2010.08895v3
- **依据**: ✅ 已读全文（arXiv v3：§1–6 和附录 A 数据生成、谱分析、贝叶斯反问题图；Table 1/3/4 的数值在文本提取中部分丢失）。标【推断】的是我们的映射。

> 一句话（摘要）：神经算子学习**函数空间之间**的映射，可以学到整族 PDE，而不是只求解单个实例。FNO 直接在**傅里叶空间**参数化积分核。在 Burgers、Darcy、Navier–Stokes 上测试，是第一个以零样本超分辨率成功建模湍流的 ML 方法，**比传统 PDE 求解器快达三个数量级**，在固定分辨率下精度也优于以前的学习型求解器。

## 1. 瓶颈
参数化 PDE 需要针对不同参数反复求解（如反问题要数千次正向评估），细网格求解很慢（§1）。

## 2. 手段
- Fourier 层：FFT → 截断到 k_max 个模态 → 线性变换 → 逆 FFT，再加局部线性项和非线性激活。
- 复杂度准线性 O(n log n)，但"**a uniform discretization is required**"（§4）。
- 网格无关：可以在低分辨率上训练、在高分辨率上评估（零样本超分辨率：64×64×20 训练 → 256×256×80 评估，时空都能超分）。
- 设置：4 个 Fourier 层，k_max = 12（2D）或 16（1D）；N = 1000 训练样本、200 测试样本；500 个 epoch；单块 V100。

## 3. 省在哪一项
**每步计算 / 运行次数**（训练好之后每次评估很便宜）。

## 4. 快了多少，代价是什么（原文）
- 256×256 Navier–Stokes：FNO 推理 **0.005 s**，伪谱求解器 **2.2 s**（约 440 倍）；传统求解器已调到不发散的最大时间步（MCMC 中用 2×10⁻²，生成数据时用 10⁻⁴），两者都在 GPU 上。
- 精度（64×64 固定分辨率）：相对以前的学习方法，误差在 Burgers 上低 30%、Darcy 低 60%、Navier–Stokes（ν = 10⁻⁴）低 30%；整条时间序列 ν = 10⁻³ 时误差 < 1%，ν = 10⁻⁴ 时 8%。**数据不足时（ν = 10⁻⁴ 或 10⁻⁵，N = 1000）所有方法误差都 > 15%**。
- 原文在 §5 明确说**不与传统求解器（FEM/FDM）比较**精度，加速数字只来自推理时间。
- §5.5 贝叶斯反问题（30,000 次正向评估）：FNO 约 2.5 分钟，传统求解器超过 18 小时；**算上数据生成和训练的 12 小时**，FNO 仍然更快。
- 代价（§6）：依赖数据的质量和数量，例如 ν = 1e−4 的 Navier–Stokes 需要 10,000 个训练对；对更难的 PDE，生成几个训练样本就可能很贵。

## 5. 怎么证明结果没变
测试集相对 L2 误差；与 U-Net、ResNet、TF-Net、GNO、MGNO、PCANN、低秩算子（类似 DeepONet）等基线比较；反问题中（25,000 个后验样本 + 5,000 个 burn-in，7×7 个观测点）FNO 与传统求解器得到的后验均值"almost the same"（只有图，没有数值误差）。

## 6. 假设
- 输入输出是**规则网格上的连续场**（FFT 需要均匀离散）；训练和测试来自同一分布（初始条件都从固定的高斯测度中抽取）。
- 非周期边界也能处理（靠局部线性项 W），高频模态由非线性激活恢复。

## 7. 能否用于 MATSim？怎么用
**❌ 不适用：**
- 【推断】MATSim 的路网是不规则图，不是规则网格（本文明确要求均匀离散）；没有 PDE；状态是离散的 agent 方案。
- 【推断】本文的加速收益来自"外循环需要成千上万次正向求解"，而且训练成本（12 小时）要靠大量重复使用才能摊薄。MATSim 的问题是单次运行内的迭代，同一场景的"正向求解"对应一轮 mobsim，训练数据的生成成本难以摊薄。
- 即使改用图上的神经算子，也会遇到 [39](39_SanchezGonzalez2020_GNS.md) 相同的问题，而且不针对"探索太慢"这个主问题。列入对照表"不适用"一栏。
