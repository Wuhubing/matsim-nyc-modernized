## 1. 想做什么

用一个神经网络改进 MATSim 的搜索：给定**城市状态**和**这个人的情况**，判断一个方案对他好不好，从而只提议有希望的方案。网络只提议，不打分、不决定（总纲第 1.4 节和 RQ1 的规则）。

- **城市 latent**：所有人的选择汇总出的城市状态（各小区各小时的拥堵），压成每个小区 × 小时一个向量。相当于平均场：每个人只对汇总状态做反应。
- **agent latent**：这个人的活动链、时间约束和他记忆里的方案，压成一个向量。
- **方案表示**：方案经过的小区、时段、方式，从城市 latent 里取对应的向量组合起来。

这一步**只检验网络设计本身**：城市 latent、agent latent、两者的交互，各自有没有用。

## 2. 任务

> 第 k 轮有人试了一个新方案。用第 k 轮之前就有的信息，预测"新方案执行后的得分是否高于被复制的旧方案"。

- 这正是提议器需要的能力，也和 H1 离线检查（`archive/h1-proposal-predictor.md`）用同一个问题，所以有现成的参照：
  - 用旧方案得分预测：改时间 AUC 约 0.70，找路约 0.73；
  - 用"同区域、同换法的人以前的结果"预测换方式：AUC 约 0.86。
- 标签：新方案第 k 轮的执行得分（`replanning-log/agents-k.csv.gz`，`plan_created == k` 的行）减去旧方案存的得分（同一快照里 `parent_plan_id` 对应的方案）。> 0 为"更好"。另外报告"明显更差"（< −3）。

## 3. 数据（全部已有）

RQ1 基线 3 个种子（`rq1/baseline-s47{11,12,13}-100it-rq1`，路径见 `experiments.md`）。

| 用途 | 文件 | 说明 |
|---|---|---|
| 方案内容 | `ITERS/it.k/BUILT.k.plans.xml.zst`，k = 10, 20, …, 70 | 每人记忆里的方案（含第 k 轮新创的、还没执行的那个）：每段出行的方式、出发时间、起讫坐标 |

**样本量估计：** 每轮约 30% 的居民试新方案，约 10 万人次；7 个快照 × 3 个种子，约 200 万个样本。先抽 5 万人跑通。

## 4. 网络

```
城市编码器    小区 × 小时的特征 → 图网络（小区相邻关系）→ e[小区, 小时]（32 维）
agent 编码器  活动链（类型、所在小区、结束时间）+ 记忆摘要 → 小 Transformer → z（64 维）
方案编码器    每段出行一个 token：方式、出发小时、e[起点, 小时]、e[终点, 小时]
              → 小 Transformer → h（64 维）；新方案和旧方案各算一个
打分头        MLP([z, h_新, h_旧, z⊙h_新, z⊙h_旧, 旧方案得分]) → "新方案更好"的概率
```

- **小区：** 2 km 方格。NYC 约 250 个格子，加上外来通勤者的门户点。
- **城市特征（第一版只有道路）：** 每格每小时的小汽车通行时间 / 自由流时间（按进入数加权）、进入数。公交的拥挤程度这一版没有：`link-hours` 只有公交车辆的通行时间，没有乘客等车。这是已知缺口，写进结果。
- **图：** 相邻格子连边，另加每个人"家 → 主要活动地点"的虚拟边（借 Liu & Meidani 2023）。
- **规模：** 总参数量控制在 100 万以内。

## 5. 检验：消融

| 版本 | 改动 | 回答 |
|---|---|---|
| 完整网络 | — | 能做到多好 |
| 去掉城市 latent | e 换成可学的常数（不随城市状态变） | 城市状态有没有用 |
| 去掉 agent latent | z 只用人群和出行数，不用活动链和记忆 | agent 表示有没有用 |
| 去掉交互 | 打分头去掉 z⊙h 项 | 城市与 agent 是否需要交互 |
| 不学习的参照 | 只用旧方案得分（H1 的做法） | 网络值不值得做 |

- **划分：** 种子 4711 训练（同种子的 10% 做验证、早停），种子 4712 测试；同一组人。
- **指标：** AUC；按试新方案的类型（换方式、改时间、找路）、收费区相关与否、人群分开报告。
- **每个版本训练 3 次（不同初始化）**，报告均值和范围。差别小于范围的不算差别。

## 6. 预期和判断（先写下，结果出来后不改）

- **预期：** 完整网络在换方式上接近或超过 0.86，在改时间、找路上明显超过 0.70–0.73；去掉城市 latent 主要影响找路和改时间（它们直接取决于拥堵）；去掉 agent latent 主要影响换方式和改时间（取决于活动链和时间约束）。
- **继续的条件：** 完整网络在三类试新方案上都比不学习的参照高 ≥ 0.03 AUC，而且去掉城市或 agent 至少一项会让 AUC 下降 ≥ 0.02。满足就写 MATSim 探针计划（单独审批）。
- **简化：** 某一项去掉后 AUC 下降 < 0.01，下一版就删掉它。
- **停下来想：** 完整网络不比参照高 0.03，说明问题不在结构，回头检查任务和数据。
